## 📦 Backend Implementation

### Models Created:
1. **Earning Model** (`backend/src/models/Earning.js`)
   - Teacher, course, payment references
   - Amount, currency, earning type (course_sale, referral, bonus, commission)
   - Status tracking (pending, available, paid, cancelled)
   - Month and year tracking for monthly breakdowns
   - Referral code and bonus reason tracking
   - Payout request linkage

2. **PayoutRequest Model** (`backend/src/models/PayoutRequest.js`)
   - Teacher reference
   - Amount, currency, status (pending, approved, processing, completed, rejected, cancelled)
   - Payment method (bank_transfer, paypal, stripe, other)
   - Payment details (account info, PayPal email, etc.)
   - Earnings linked to request
   - Approval workflow tracking
   - Payment slip reference

3. **PaymentSlip Model** (`backend/src/models/PaymentSlip.js`)
   - Payout request and teacher references
   - Slip number auto-generation
   - Amount, currency, period (start/end dates)
   - Earnings breakdown
   - PDF URL for download
   - Generated by admin

### Controllers Created:
**`backend/src/controllers/earningController.js`** with 9 endpoints:

**Teacher Routes:**
- `GET /api/v1/earnings/summary` - Get earnings summary with breakdowns
- `GET /api/v1/earnings/monthly` - Get monthly earnings breakdown
- `GET /api/v1/earnings/courses` - Get earnings by course
- `GET /api/v1/earnings/referrals` - Get referral earnings
- `POST /api/v1/earnings/payout-requests` - Create payout request
- `GET /api/v1/earnings/payout-requests` - Get payout requests
- `GET /api/v1/earnings/payment-slips` - Get payment slips

**Admin Routes:**
- `PUT /api/v1/earnings/payout-requests/:requestId` - Update payout request status
- `POST /api/v1/earnings/payment-slips` - Generate payment slip

### Routes:
- **`backend/src/routes/earningRoutes.js`** - All earnings routes
- Connected to **`backend/src/app.js`** at `/api/v1/earnings`

## 🔄 Earnings Flow

1. **Earning Creation:**
   - Earnings created from course sales
   - Automatic month/year assignment
   - Status set to "pending" initially
   - Moved to "available" when ready

2. **Payout Request:**
   - Teacher creates payout request
   - Available earnings validated
   - Earnings linked to request
   - Status set to "pending"
   - Admin reviews and approves/rejects

3. **Payment Processing:**
   - Admin approves request
   - Status updated to "approved" or "processing"
   - Payment slip generated
   - Status updated to "completed"
   - Earnings marked as "paid"

4. **Payment Slip:**
   - Generated by admin after approval
   - Contains earnings breakdown
   - Includes period information
   - PDF available for download
